What is MJOLNIR3?

MJOLNIR3 is a powerful tool designed to crush large amounts of raw metabarcoding data and forge them into organized datasets of taxonomically assigned MOTUs.

Distributed as an R package, MJOLNIR3 enables modular metabarcoding workflows to be executed directly from R while maintaining reproducibility and flexibility.

MJOLNIR3 is primarily designed for Linux and macOS systems. While installation through WSL may be possible, native Windows installations are not recommended.

⚡ Step 0 - Prepare Input Data

Get the Input files ready and define the project settings.

Pipeline Settings

Project Name

Unique identifier used throughout the MJOLNIR3 analysis. For simplification it is restricted to 4 digits.

Metadata File

Provide the path to the metadata file containing sample information required for the MJOLNIR3 analysis.

Columns required:

  • original_samples
  • mjolnir_agnomens ({library identifier}_sample_{three digits number}, i.e. LIB1_sample_001)
If demultiplexed libraries, include an additional column:
  • fastq_name_R1

Library identifiers must have exactly 4 characters.
ngsfile_LIB1.tsv

*Prepare one file for each library and rename them according to the library identifier.

ngsfilter File

Provide the path to the ngsfilter file required for the MJOLNIR3 analysis. This is a tab separated file without a header row.

One file for each library is required.

Columns required:

  • library identifier (four characters)
  • mjolnir_agnomens ({library identifier}_sample_{three digits number})
  • sample tags
  • forward primer
  • reverse primer
Example:
#Lib mjolnir_agnomens Sample tags Forward primer Reverse primer
LIB1 LIB1_sample_001 ATCG:ATCG GGWAC... TANAC...
LIB1 LIB1_sample_002 TAGC:TAGC GGWAC... TANAC...

Cores or Threads

Specify the number of CPU cores or threads to use for parallel processing in the MJOLNIR3 analysis.

⚡ Step 1 - RAN: Demultiplexing and primer trimming

The output of this step can be directly uploaded to ENA/SRA repositories.

RAN

In this step MJOLNIR3 validates and prepares the raw sequencing files before entering the downstream workflow. Experiment with multiplexed libraries require demultiplexing for pipeline processing but also to store the data in reprositories such as ENA or SRA. One of the most common software for demultiplexing and primmer trimming is "cutadapt", the core program in RAN.

RAN performs a two step cutadapt process for demultiplexing and primer trimming.

Step 1 identify sample tags from the R1 and R2 sequence reads and distributes the sequences into separate files based on the identified sample tags.

Step 2 reorientate the sequences based on the primers and trims them accordingly.

Step 3 finally complete the process concatenating the intermediate files into the final output.
